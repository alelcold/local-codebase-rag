- **Missed keywords**: `onPlayerHit / COMBO_WINDOW_MS`

<details><summary>Answer</summary>

~~~~text
ScoreSystem 的 multiplier 是根據 combo 的值計算的。在 [1] 檔案的 12-30 行，有以下程式碼：

```typescript
get multiplier(): number {
  return Math.min(MAX_COMBO_MULTIPLIER, 1 + this.combo * COMBO_STEP);

```

這段程式碼表示 multiplier 的計算方式是：首先將 combo 的值乘以 COMBO_STEP，然後加上 1，最後取最小值，限制在 MAX_COMBO_MULTIPLIER 以內。
~~~~
