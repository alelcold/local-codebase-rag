- **Missed keywords**: `onPlayerHit / COMBO_WINDOW_MS`

<details><summary>Answer</summary>

~~~~text
ScoreSystem 的 multiplier 是根據以下公式計算的：

```typescript
Math.min(MAX_COMBO_MULTIPLIER, 1 + this.combo * COMBO_STEP);
```

這段程式碼在 `ScoreSystem` 的 `getMultiplier` 方法中，根據連擊數 `this.combo` 和連擊步長 `COMBO_STEP`，計算出連擊倍率 `multiplier`，並確保倍率不會超過最大連擊倍率 `MAX_COMBO_MULTIPLIER`。
~~~~
