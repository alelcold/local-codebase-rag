# 玩法規則

## 操作

- 方向鍵 / WASD：移動
- Shift：衝刺（dash），有冷卻時間
- Esc：暫停 / 繼續
- Enter：開始遊戲 / 重新開始

## 生命與受傷

玩家一開始有 3 條命（`PLAYER_MAX_LIVES`）。撞到小行星會失去 1 條命，
並進入無敵狀態 `INVINCIBLE_MS` 毫秒，期間飛船會閃爍且不會再受傷。
衝刺期間也視為無敵。

## 計分

- 收集包裹：基礎 100 分（`PACKAGE_SCORE`）
- 連續收集包裹會累積連擊，倍率 = 1 + 連擊數 × 0.25，最高 4 倍
- 超過 `COMBO_WINDOW_MS` 沒有收集到包裹，或是受傷，連擊歸零
- 每存活 1 秒額外加 5 分

## 關卡

每收集 `PACKAGES_PER_LEVEL` 個包裹進入下一關。關卡設定在 `src/config/levels.js`，
越後面的關卡小行星生成越頻繁、速度越快。
